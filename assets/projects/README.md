# AKIRA — visuales para concierto

Créditos confirmados por el usuario: **David Picón**, integrante del equipo de Criollo. **Modelado 3D en Blender** para visuales de un concierto de AKIRA.

Las dos piezas pertenecen al mismo caso y se muestran con crédito individual. Los títulos describen lo que aparece en los videos: lettering cromado y personaje en 3D.
